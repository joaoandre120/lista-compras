\## 2. Regras de Git e Ambientes (GitHub + Codeberg)

\- \*\*Fluxo Duplicado:\*\* Este projeto utiliza um fluxo de commits duplicado para o GitHub (`origin`) e para o Codeberg (`codeberg`). Sempre que sugerir comandos de Git para atualizar o repositório, lembre-me de enviar para ambos os remotos ou me dê os comandos específicos para essa estrutura.

\- \*\*Commits Atômicos:\*\* Faça commits pequenos, focados e frequentes (um commit por tarefa resolvida), garantindo que modificações rastreadas recebam o devido `git add` antes do commit.

\- \*\*Conventional Commits:\*\* Todas as mensagens de commit devem seguir rigorosamente o padrão \*Conventional Commits\* (`tipo: descrição curta`). Os prefixos obrigatórios para este projeto são:

&#x20; - `feat:` Para novas funcionalidades ou implementações inéditas.

&#x20; - `fix:` Para correções de bugs, erros de compilação ou incompatibilidade de dependências (Gradle/Kotlin).

&#x20; - `docs:` Para alterações exclusivas em documentações ou KDocs.

&#x20; - `style:` Para formatações de código que não alteram seu comportamento.

&#x20; - `chore:` Para atualizações de rotina em arquivos de configuração ou ferramentas.
